# Technical Assessment Projects

This repository contains the completed implementations for the technical assessment tasks.

## 1. Automated File Organizer (`organizer.py`)
A robust Python utility designed to clean up cluttered directories by sorting files into dedicated folders based on their extensions.
* **Key Features:** Input directory verification, automated category subfolder creation, safety exception handling for locked files, and an end-of-run execution summary.
* **How to Run:**
  ```bash
  python organizer.py
  ```

## 2. Interactive Terminal Assistant / Chatbot (`chatbot.py`)
A rule-based conversational chatbot designed to parse customer support queries and simulate a standard product assistant.
* **Key Features:** Input string normalization (lowercase and whitespace removal), multi-intent keyword matching (greetings, business hours, product FAQs), fallback messaging, and clean terminal exit commands (`bye`, `exit`, `quit`).
* **How to Run:**
  ```bash
  python chatbot.py
  ```
